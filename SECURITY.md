# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability on Plaintext Privacy, please report it responsibly. Do not open a public GitHub issue.

**Email:** plaintextprivacy@proton.me

Please include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Relevant URLs, screenshots, or proof-of-concept code

You can expect an acknowledgement within **2 days** and a resolution timeline within **7 days** of the initial report for most issues.

---

## Scope

This covers the Plaintext Privacy website at **plaintextprivacy.org** and its source code.

**In scope:**
- Cross-site scripting (XSS)
- Content injection or data tampering
- Dependency vulnerabilities with demonstrated exploitability
- Data leaks that contradict our stated data practices

**Out of scope:**
- Automated scanner results without demonstrated exploitability
- Issues requiring physical access to a user's device
- Social engineering attacks
- Issues in third-party services we have no control over (GitHub, Cloudflare)

---

## What We Commit To

- We will acknowledge your report promptly
- We will not take legal action against researchers acting in good faith
- We will credit you in the fix if you'd like recognition
- We will keep you informed as the issue is investigated and resolved

---

## Supported Versions

Only the current production deployment at **plaintextprivacy.org** is actively maintained.

---

## Disclosure Policy

We follow **coordinated disclosure**. Please give us reasonable time to investigate and patch before publishing details publicly.
